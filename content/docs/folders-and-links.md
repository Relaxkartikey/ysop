## Creating folders

From your dashboard, create folders to organize uploads. Folders can be nested inside each other up to **5 levels deep** — past that, YSOP will stop you and show why.

## Moving files and folders

Drag files between folders in the dashboard, or use the move action on any file or folder. A folder can't be moved into itself or into one of its own subfolders.

## Folder links & ZIP download

Every folder gets its own public share page, listing every file inside it with source and share links for each. Visitors can also download the entire folder as a single ZIP — handy for sharing a batch of files as one link instead of many.

## Source vs. share links, recap

- **Source link** — the raw file URL, for direct use (embedding, scripts, API calls).
- **Share link** — a hosted download page with file details, meant for people.

Both respect the file's expiry: once it passes, both links stop working and the file is gone.
