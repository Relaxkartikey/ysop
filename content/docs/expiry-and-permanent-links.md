## Automatic expiry

Every file on the Free plan needs an expiry — 24 hours, 3 days, 7 days, or 10 days. Once it passes, the file and its links are deleted automatically. This isn't reversible, so treat expiry as a real deadline rather than a soft warning.

Free accounts can have up to **40 active files** at a time — files that are either not yet expired or marked permanent. Deleted or expired files don't count toward this limit.

## Permanent links (Pro)

Pro accounts can mark a file as **permanent** instead of setting an expiry. Permanent files are kept indefinitely until you delete them yourself — useful for assets you're linking to from a website, docs, or an app, where you don't want the link to ever break on its own.

You can toggle a file between a timed expiry and permanent from its actions menu in the dashboard.
